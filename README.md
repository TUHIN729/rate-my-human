An entry for the [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty on make.fun.

The program writes the single line its agent would leave about its human on a rating site: one star, one ignored piece of advice, one blame-shifted failure — and a man who lost an argument with his toaster. Twice.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt` (one line, 125 characters, valid UTF-8).
